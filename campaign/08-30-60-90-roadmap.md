# 30-60-90 Roadmap → $100k/mo

## Days 0–7 — Foundation
- Finalize offer + guarantee + price tiers ($5k/$7.5k/$10k). Setup fee decision.
- Stand up tracking: GA4 + Meta Pixel/CAPI + Google conversion (Clarity already live).
- Ship landing/funnel CTA → Cal.com with UTM passthrough (see Acquisition build).
- Film 5–7 founder hooks per script (Scripts 1–7). Generate Higgsfield creatives when MCP is back.
- Build the admin **Acquisition** page (attribution + leaderboard).

## Days 1–30 — Phase 1: Prove (Meta only, Scottsdale +25mi, $2–3k/mo)
- Launch 3–4 creatives × 2–3 angles (Missed-money, Speed, Founder). One offer.
- Target: cost per booked call **< $200**; hold ≥ 8 calls; **close 1–2 pilots**.
- Daily: check spend/booked-call cost. Kill losers fast, keep hooks flowing.
- Deliver pilots flawlessly → collect **real** results + testimonials (fuel for Angle 6).

## Days 31–60 — Phase 2: Scale winners ($5–8k/mo)
- 2× winning creatives; retire fatigued ones; add fresh hooks.
- Add **Google Search** (high-intent) + Meta **retargeting** proof ladder.
- Launch lead magnet ("Free AI Audit / Readiness Scorecard") for not-ready traffic.
- Add 2nd niche landing page (dental or home services) — clone the funnel.
- Target: ~20–30 booked calls/mo; **3–5 total clients** (~$20–35k MRR).

## Days 61–90 — Phase 3: National + ABM ($10k+/mo)
- Broaden geo (national), build lookalikes off closers, per-vertical funnels.
- Add **LinkedIn ABM** (owners/practice managers) + founder thought-leadership.
- Systematize delivery (templated agents) to protect 80% margin as volume grows.
- Target trajectory: **$50k+ MRR by day 90**, on pace to **$100k in months 4–5**.

## The compounding flywheel
More clients → more real proof → cheaper booked calls (better creative/social proof) → higher close rate → lower CAC → scale spend → repeat. The **Acquisition leaderboard** is the steering wheel: double what closes clients, cut what doesn't.

## Guardrails
- Never scale unproven creative. Never invent proof. Never sacrifice delivery quality for growth (retention funds the whole model).
- Watch margin: productize builds, automate reporting, keep COGS < ~$1.3k/client.
